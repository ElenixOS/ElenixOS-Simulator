# Infograph image assets

`icons/globe-realistic.png` is an isolated transparent globe icon. The analog dial uses the transparent pointer images in `hands/`: a rounded baton for the hour hand and a fine pointed needle for the minute hand.

`icons/clock-orange.png` is a display-size copy of the supplied high-resolution transparent clock icon. The music symbol remains the built-in RemixIcon `RI_MUSIC_FILL` (U+E583), whose source and Apache-2.0 license are maintained by the ElenixOS submodule.
